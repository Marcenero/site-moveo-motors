# Moveo Motors

Site institucional e plataforma de gerenciamento de veículos desenvolvida para a **Moveo Motors**.

O projeto tem como objetivo apresentar o estoque da loja de forma moderna, responsiva e intuitiva, além de disponibilizar uma área administrativa para gerenciamento dos veículos publicados no site.

## Features

### Site público

- Visualização dos veículos disponíveis
- Página individual
- Exibição de informações detalhadas dos veículos
- Filtros e ordenação de estoque
- Exibição de veículos recentes
- Página de serviços da loja
- Links de contato
- Acesso à localização da loja
- Layout responsivo para diferentes tamanhos de letra

### Área administrativa

- Autenticação exclusiva para administradores
- Cadastro de veículos
- Edição de veículos
- Remoção de veículos
- Upload e gerenciamento de estoque
- Controle de acesso às rotas administrativa
- Registro de operações realizadas no sistema


## Google Analytics

O projeto utiliza **Google Analytics 4** para acompanhamento de métricas relacionadas ao uso do site.

Entre as informações que podem ser analisadas estão:

- Quantidade de visitantes
- Visualizações de páginas
- Páginas mais acessadas
- Origem dos acessos
- Dispositivos utilizados
- Interações com elementos importantes do site

Também podem ser configurados eventos específicos para acompanhar ações relevantes para a loja.
